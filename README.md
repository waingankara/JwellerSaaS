# JwellerSaaS

Jewelry SaaS backend foundation.

## What is included in this first commit
- .NET 9 solution structure
- Clean Architecture folders
- ASP.NET Core Web API
- Swagger
- Serilog
- Dapper
- PostgreSQL connection setup
- Health endpoint
- Global exception middleware
- Standard API response model

## Run
Open `backend/JwellerSaaS.sln` in Visual Studio 2022 or run:

```bash
cd backend/src/JwellerSaaS.Api
dotnet restore
dotnet run
```
